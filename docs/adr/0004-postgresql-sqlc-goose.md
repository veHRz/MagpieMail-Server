# 0004. PostgreSQL with pgx, sqlc and goose

- Status: Accepted
- Date: 2026-10-06
- Deciders: veHRz

## Context

Metadata (users, accounts, messages, rules…) needs transactions, full-text
search, JSON for rule definitions, and reliability.

## Decision

- PostgreSQL, latest major version (18 at the start of the project), used through pgx.
- Typed queries generated by sqlc; one repository per aggregate; explicit transactions.
- Migrations managed by goose, run by `magpie migrate`.
- Identifiers are UUIDv7 (time-ordered); timestamps are stored in UTC.

## Consequences

The compose stack and the integration tests run the same PostgreSQL image; a
test and Renovate keep them aligned. Large files do not go into the database
(ADR 0006).

## Alternatives considered

An ORM: less control over queries and indexes, and harder to review.
